# 官方要求（TalentsAI 专家出题平台）

来源：题目活动页「项目说明」「题目内容」「参考答案」「评分规则」各栏目的说明文字。

## 1. 项目说明

- 平台提供《Excel出题平台快速上手指南》视频。
- 专家有任何问题可加入官方微信群讨论。
- 提示：本项目模型和难度修改要求为「模型1 ≤ 65%，模型2 ≤ 65%」。
- 机评结果仅供专家参考，请专家以培训材料为准出题，并对模型回复进行评分；如有与机评结果不一致的地方需要备注。

## 2. Excel 任务文本（prompt）规范

Excel 任务文本必须是一个具有明确要求的、专业且实际的 Excel 作业。

i. 必须明确写出 **工作表名称**，以对应每个具体任务。

- ❌ 错误：请使用图像和当前工作表，完成主工作表上的缺失条目。填充财务数据行，使五年数据和总计数据完整且与文件的其余部分一致。如果特定部分没有参考资料，则留空。
- ✅ 正确做法：请使用图像和当前工作表完成 '五年回顾'工作表上缺失的条目。填充'五年回顾-财务数据'行，使五年的数据和总计都填写完整，并与文件的其他部分保持一致。如果特定部分没有参考资料，则留空。

ii. 当任务涉及从头开始生成新的工作表时：

1. 确定一个逻辑名称：由于没有源文件可供提取名称，因此根据工作表将包含的数据创建一个专业的、符合行业标准的名称（例如，使用 'Q1总结' 而不是 '工作表1'）。
2. 将其包含在提示中：明确告知用户/AI 使用这个特定名称。
3. 匹配参考答案：确保参考答案输出使用完全相同的名称。

iii. 如果需要图表，提示必须明确说明：(a) 要绘制的确切数值，以及 (b) 特定的格式要求（例如，"柱状图"、"趋势线"、"无网格线"）。

## 3. 任务文件与参考答案的硬性约束

- 题目不能依赖于对外部信源的搜索、下载；所有需要处理的数据都必须包含在上传的任务文件中。
- 上传材料最多 5 个文件。
- 文件名不超过 255 个字符，不得包含 `< > : " | ? * \ /` 等特殊符号，也不得包含换行、回车或制表符。
- 参考答案文件命名不要与任务文件同名；参考答案文件数量可为多个；**文件应有大于等于 200 个带内容单元格**。
- 任务文件锁定后作为唯一基线；解锁会清空模型结果与相关 AI 检测。
- 参考答案文件锁定后，质检/抽检如需修改要先解锁，修改后需重新锁定并重新完成参考答案文件检测。

## 4. 任务类型

本题勾选的任务类型：**分析数据**、**呈现洞察**。

平台给出的类型定义：

- 获取数据：从网页下载公开数据，从系统导出报表 CSV 等。
- 清洗与转换数据：去重、补全缺失值，统一口径与字段命名，拆分合并列与格式化等。
- 分析数据：做敏感性与压力测试，建立预测模型与假设表，计算 KPI 与同比环比，做情景分析与变量联动，进行相关回归与归因拆解等。
- 呈现洞察：制作图表与仪表盘，输出结论与要点摘要等。
- 检查并纠正错误：查找断链与引用错误，排查异常值与口径问题，复算关键公式结果，校验输入输出逻辑等。

## 5. 平台自动检测（AI 辅助，仅供参考，不代表最终结论）

平台在提交前会跑三类检测，专家可以填写「不同意原因」继续作业：

1. **Task 内容检测** — 判定 prompt 是否像真实工作委派，还是像用于确定性评分的答案键/基准规范。
2. **参考答案文件检测** — 判定参考答案是否违反 prompt 中明确规定的单元格位置、命名、格式要求，以及是否满足 ≥200 带内容单元格等硬性条件。
3. **评分规则拆分检测 / 人机评一致率检测** — 检查评分规则拆分是否与题目一致、人工评分与机器评分是否一致。

第 1 轮中，Task 内容检测判定「未通过」，理由摘要：

> 【Natural Professional Tone vs Synthetic Benchmark Scaffolding】任务场景和专业术语真实，且数据来源、工作表名称及逻辑边界总体清晰；但提示词以大量固定区域、逐列公式、阈值、图表设置和核对关系封闭式规定完整流程，覆盖从收益计算、归因、压力测试到回测的几乎每个执行细节。其指令密度和单元格级脚本化程度明显更像用于确定性评分的答案键或基准规范，而不是同事在真实工作中的自然委派。

第 1 轮中，参考答案文件检测判定「未通过」，理由摘要：

> 行业风险归因、风险回测、压力测试多个指定区域整体上移一行（例如"行业风险归因"的收益数据位于 A3:H25 而非 A4:H26，协方差矩阵位于 B32:G37 而非 B33:G38，汇总位于 B40:B44 而非 B41:B45；"风险回测"的检验区位于 A3:J13 而非 A4:J14，汇总位于 B16:B19 而非 B17:B20；"压力测试"情景汇总位于 J3:L5 而非要求的 J4:L6）。此外"组合分析"VaR 贡献列标题为"月度VaR贡献"，未明确包含要求的"95%单尾"表述。

## 6. 评分与难度规则

- 评分规则由「评分规则拆分」自动生成草稿，专家需要实质性修改、补充与完善。
- 每条规则包含：任务描述、标签（内容质量 / 专业规范 / 指令遵循 / 格式规范 / 文件管理·操作）、分值。
- 默认规则含 1 条正向「主要交付文件存在」规则（1 分）与多条扣分规则（格式/排版/改动无关部分等，-5 分）。
- 提交时校验：每个模型的得分率都不能超过 65%（模型一 / 模型二）。
- 分值分布统计（第 1 轮）：高分值（+7～+10）11 条、中分值（+4～+6）14 条、低分值（+1～+3）4 条、扣分规则 3 条，合计 32 条。
