## 出题方向（拟）

**A 股上市公司控股股东股权质押的平仓风险测算与信披合规分析**

理由：

1. 属「经济金融 / 投资 / 股票」，与专家领域匹配（不匹配会被判不通过）。
2. 中国特色明显：预警线/平仓线 150%/130% 惯例、质押新规的集中度上限、
   补充质押与强制平仓的信息披露要求，模型容易只算数不讲规则。
3. 计算链条长：维持担保比例 → 触线判定 → 安全边际（股价跌幅）→ 组合层面的
   集中度校验 → 处置建议，任何一步口径错都会传导到结论。
4. 结论需要专业判断（哪些户必须补质押、哪些要提前减仓），不是查得到的事实。

## 拟用附件

`股权质押数据表.xlsx`：12 家上市公司，列含
股东名称 / 质押股份数（万股）/ 融资额（万元）/ 质押日股价 / 最新股价 /
预警线 / 平仓线 / 该股东持股比例 / 该股质押占总股本比例。

## 拟写题目内容（草稿）

你是券商研究所金融工程组的资深研究员。请基于附件《股权质押数据表.xlsx》，
为机构客户完成一份 A 股控股股东股权质押的风险体检，仅使用附件中的数据，
不得引入外部行情。

具体要求：

1. 逐户计算维持担保比例（＝质押股份数 × 最新股价 ÷ 融资额），保留两位小数；
2. 按预警线 150%、平仓线 130% 判定每户当前处于「正常 / 预警 / 平仓」哪一档；
3. 对非「正常」的账户，测算股价还需下跌多少个百分点会分别触及预警线与平仓线
   （＝1 − 对应线 × 融资额 ÷ 质押市值），保留两位小数；
4. 结合 A 股股权质押的集中度与信息披露常识，指出需要立即补充质押或提前减仓的
   账户，并说明你依据的规则；
5. 用不超过 800 字输出一份结论先行的专题分析，至少包含：整体风险档位分布、
   风险最高的三个账户及其量化依据、一条可执行的风险控制建议。
